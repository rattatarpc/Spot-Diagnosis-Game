# Spot Diagnosis Game

Static frontend with Firebase Realtime Database and optional Gemini grading.

## Local checks

Install the free development dependency once with `npm install`, then run:

- `npm test`
- `npm run lint`

## Free deployment

The app can be deployed as static files using GitHub Pages, Firebase Hosting, or any static hosting service. No build step is required. Keep API keys out of public repositories and use Firebase Security Rules for database access.
