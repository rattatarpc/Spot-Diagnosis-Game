Answer Key Guide

1. Adding Synonyms

If there are multiple correct ways to say the same thing, separate them with a slash /.

ECG / EKG / Electrocardiogram

2. How does grading work?

  • Default (Forgiving): Ignores spelling mistakes (up to 2 letters wrong, e.g. dilated → diltaed) and word order. (e.g. LV enlarged → enlarged lv passes). NOTE: Completely different word forms like dilatation are NOT counted as spelling mistakes and require a synonym!
  • Ordered: Ignores spelling and extra words, but words MUST be in sequence. (e.g. Tall T wave → Tall peaked t wave passes. T wave tall fails).
  • Exact: The strictest mode. No spelling mistakes or extra words allowed anywhere. (e.g. LV → LV passes. It is LV fails).

3. The "Missing Word" Rule (Default & Ordered Modes)

Depending on how long your answer key is, the game allows players to forget words:

  • Short phrases (1-2 words): Must match all words.
  • Medium phrases (3-4 words): Allows the player to miss exactly 1 word.
  • Long phrases (5+ words): Allows the player to miss exactly 2 words.

4. The "Negative Findings" Rule

If your answer key contains a critical negative word (no, not, without, none, absent, absence, or negative):

  • The player MUST include that exact negative word (the "Missing Word" rule above does not apply to it).
  • The negative word MUST be typed close to the rest of the phrase to prevent false matches across different sentences.

5. "Follows previous key"

If you check this box on a key, the student will ONLY earn points if they type it immediately after the previous key (within 5 words).

e.g. Key 1: ST depression, Key 2: inferior leads (Follows previous).
If student types: "ST depression is in the inferior leads" → Passes.
If student types: "In the inferior leads, we see ST depression" → Fails.

6. Points

Set the exact points you want to award the player. If a player gets ALL your keys, they receive a massive 150 Point Bonus!
